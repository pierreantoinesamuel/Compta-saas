# Agent Skills

Use these skills as task-specific checklists. Load only the skills relevant to the current task, in addition to `agent_instructions.md` and `accounting_rules.md`.

- `accounting-domain/SKILL.md` — French (DGFiP, Code de commerce, CGI, PCG 2025, FEC) & EU (EN 16931 Factur-X, VIES) invoicing, VAT, and ledger invariants, guided by Dolibarr ERP/CRM domain workflows.
- `frontend-ux/SKILL.md` — React UI, French (`fr-FR`) financial formatting, progressive Micro vs Société UX, and EU EAA / RGAA 4.1 accessibility.
- `database-migrations/SKILL.md` — Safe PostgreSQL schema changes, RLS tenant isolation, gapless `SELECT ... FOR UPDATE` sequences, and `BEFORE UPDATE OR DELETE` immutability triggers.
- `api-security/SKILL.md` — Tenant authorization, step-up MFA, SIREN/VIES validation, idempotency, and GDPR data protection.
- `testing-and-review/SKILL.md` — Validation of EN 16931 VAT rounding, gapless concurrency, Factur-X XML, 18-column FEC compliance, and completion reporting.
